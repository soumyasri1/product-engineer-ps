Memory

An assistant that remembers what you tell it — and never repeats an old fact as if it were still true. Tell it something, then ask it something.

Not sure where to start?

Click these in order. Each one asks a question and explains what to notice in the answer.

1 Tell me something about yourself

Write it the way you'd say it to a person. Change your mind later and say so — that's the interesting part.

2 Ask me something

You'll get the current answer, plus anything I deliberately ignored.

How it decides

  • Some things you can only have one of — one home city, one employer. Others you can have many of — allergies, skills. A new allergy gets added; a new city is a contradiction.
  • "Actually, I've moved to Mumbai" replaces the old fact. Just saying "I live in Mumbai" does not — that might be a slip, a second home, or someone else. So it keeps both and asks you.
  • Nothing is quietly erased. Old facts are kept and marked as past, so you can always see how it got here.
